# Objective: [[Objectives/story_daily_core_containment|Core Containment Sweep]]

## Narrative
> A rare monster core would unlock deeper analysis packages. Recover one and stage it with rare chitin for Command.

## Requirements
- Deposit 1x **monster_core_rare** (Deposit rare monster core)
- Deposit 1x **monster_chitin_rare** (Deposit rare monster chitin)

## Rewards
- 3x **research_material**
- 1x **alloy_plate**
- 2x **circuit_boards**

## Failure Penalty
Core containment fails and Command throttles specimen support. (Defense: -2)
