# Objective: [[Objectives/story_vault_cipher_reassembly|Vault Cipher Reassembly]]

## Narrative
> Command wants proof you can reopen sealed vault systems without detonating what remains inside. Recover key fragments, recover legacy media, and reconstruct a usable access cipher before the final lock cycle.

## Requirements
- Deposit 2x **[[Items/vault_key_fragment|Vault Key Fragment]]** (Deposit vault key fragments)
- Deposit 1x **[[Items/data_tape|Data Tape]]** (Deposit data tape)

## Rewards
- 1x **[[Items/vault_key_fragment|Vault Key Fragment]]**
- 2x **[[Items/research_material|Research Material]]**

## Failure Penalty
Cipher reconstruction fails: command confidence in the station drops. (Defense: -2)
